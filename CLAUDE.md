# CLAUDE.md

Read [AGENTS.md](AGENTS.md). It is the single copy of the guidance for AI-assisted
sessions on this repository, including the Code Review Rules the automated reviewer
reads.

This file is a pointer rather than a symbolic link (which is how some sibling
repositories share one file under both names) because this module is built on
Windows, where Git checks a symbolic link out as a one-line text file unless
`core.symlinks` is enabled — a contributor there would open a file containing a path.
